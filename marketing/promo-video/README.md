# Рекламный ролик для TikTok и Instagram Reels

Вертикальное видео 1080×1920, 30 к/с, ~30 с, на трёх языках: `out/promo.ru.mp4`, `out/promo.en.mp4`,
`out/promo.th.mp4` и обложки `out/cover.<язык>.jpg`. Дорожка звука тихая — музыку добавляют в TikTok/Instagram
(трендовый звук даёт больше охвата).

Сценарий «боль → решение»:

| с | Боль | Решение | Кадр |
|---|------|---------|------|
| 0–2,4 | «Зарплата пришла… и куда-то делась» | — | вступление |
| 2,4 | Записывать траты — долго и лень | Расход за 5 секунд | окно «Новый расход», набор суммы |
| 6,2 | О перерасходе узнаёшь в конце месяца | Лимиты предупредят заранее | «Обзор», красная полоса 185 % |
| 10 | Опять забыли про аренду и подписки | Все платежи — в календаре | «Календарь», просрочки |
| 13,8 | Каждый ведёт деньги в своих заметках | Один бюджет на всю семью | «Проекты и участники» |
| 17,6 | Карты, наличные, баты, рубли — каша | Все счета и валюты в одном месте | «Счета» |
| 21,4 | Нет времени даже открыть приложение | Просто скажите Claude | переписка с Claude (как на лендинге) |
| 26,2 | — | Демо без регистрации, family-budget-555.ru | финал |

Тексты всех языков — объект `T` в `index.html`, кадры и движение камеры — `SHOTS`. Скриншоты берутся из гайдов
сайта (`site/content/guides/**/<имя>.<язык>.webp`): переснимете гайды — перерендерите ролик.

## Сборка

Нужны `npm ci`, Chromium и ffmpeg.

```bash
node marketing/promo-video/render.mjs            # все языки, ~1,5 мин на язык
node marketing/promo-video/render.mjs th         # один язык
node marketing/promo-video/render.mjs ru 7.2     # один кадр → out/frame.ru.png, для отладки
```

`CHROMIUM` — путь к браузеру (по умолчанию `/usr/bin/chromium-browser`). Предпросмотр без рендера — открыть
`index.html?lang=ru` в браузере (из корня репозитория через локальный сервер, например `python3 -m http.server`).
