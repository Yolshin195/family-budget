# Фича `people` — Люди (написана вручную по образцу places)

Для кого покупка: участники проекта и люди без аккаунта (ребёнок, няня). Позиция операции ссылается на человека
(«Для кого»), пусто — «Для всех». ТЗ — docs/group-1.md, раздел 5.9.

- **Тип:** справочник (ключ `code`, архив вместо удаления); `feature.json` нет — `upgrade` фичу не трогает
- **Крейт:** `crates/features/people` (Cargo-флаг приложения `people`); от других фич ничего не нужно
- **Таблица:** `fb_people`
- **Кто вызывает:** `projects` — записи участников (`crates/app/src/wiring/wire_projects.rs`), `transactions` и `mcp` —
  выбор и показ людей
- **Правила:**
  - человек без аккаунта — только явно (форма, REST, `add_person`); код — латиница, цифры и `_`, до 40 знаков;
  - имя не переводится; другие имена — без повторов и пустых, до 20;
  - запись участника создаётся при создании проекта и вступлении по приглашению (и при запуске приложения —
    для участников без записи), демо-гостю — нет: имя из профиля, код — латиница и цифры имени в верхнем
    регистре, остальное — `_`, без латиницы — `MEMBER`, занятый — `_2`, `_3`;
  - имя участника правится в справочнике, профиль его не меняет; повторное вступление возвращает прежнюю запись;
  - выход из проекта — запись в архив; удаление аккаунта — имя стёрто, `user_id` пустой, в архиве, показывается
    «Удалённый участник» на языке зрителя (`former_member`);
  - запись участника вручную не архивируется и не возвращается из архива.

## Поля

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| code | string | да | Уникальный код в проекте |
| name | string | да | Отображаемое имя; пусто — только у удалённого участника |
| aliases | string[] | нет | Другие имена для поиска |
| user_id | uuid | — | Участник проекта; пусто — человек без аккаунта (задаёт только `projects`) |
| former_member | bool | — | Участник удалил аккаунт |
| archived | bool | — | Архив |

## Эндпоинты

| Метод | Путь | Действие |
|---|---|---|
| POST | /api/people | добавить человека без аккаунта |
| GET | /api/people?page=0&size=100&include_archived=false | список по имени |
| GET | /api/people/{code} | получить |
| PUT | /api/people/{code} | изменить имя и другие имена |
| DELETE | /api/people/{code} | архивировать (кроме записи участника) |
| POST | /api/people/{code}/restore | вернуть из архива (кроме записи участника) |

Страницы: `/people`, `/people/new`, `/people/{code}/edit`.
