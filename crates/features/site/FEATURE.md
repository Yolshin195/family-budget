# site — Лендинг и правовые страницы (сгенерирована как blank, дальше — вручную)

ТЗ, раздел 11. Своих таблиц нет.

> Новый сайт с блогом — `site/` (Zola, site/README.md); туда скопированы тексты лендинга и правовых страниц.
> Эта фича обслуживает продакшен до переезда сайта на основной домен: тексты правим в `site/`, здесь — только по
> явной просьбе. После переезда `/`, `/privacy`, `/terms`, `/data-deletion` станут редиректами на сайт.

- `/` — гостю лендинг на языке браузера (`?lang=ru|en|th` — отдельный индексируемый адрес), вошедшему — `/budget`.
  Блоки: шапка (RU · EN · TH, «Войти», «Создать бюджет»; на телефоне — только «Войти»), первый экран со
  скриншотом «Обзора» и плашкой «Новое» (ведёт к секции Claude), 9 выгод, «Claude ведёт бюджет за вас»
  (4 сценария, пример переписки на чеке Big C из демо-данных, границы доступа — по фиче `mcp`), «Как это работает»,
  «Безопасность и приватность», «Посмотреть демо» (вход гостем, VIEWER), FAQ из 7 вопросов, финальный призыв,
  подвал. Под «Создать бюджет» на первом экране и в финальном призыве — «Уже есть аккаунт? Войти»:
  на странице регистрации Rauthy ссылки на вход нет. Кнопок «Войти через GitHub / Facebook» на лендинге нет —
  эти способы предлагает страница входа Rauthy.
- Тексты, которые шаблон собирает через `format!` (карточки, шаги, FAQ, строки чека), проверяет отдельный тест:
  при новой карточке или вопросе — добавьте ключ и в список теста.
- `/privacy`, `/terms`, `/data-deletion` — обязательны для Facebook; `/data-deletion?done=1` — после удаления аккаунта.
- SEO: title, description, Open Graph, hreflang + x-default, canonical, `sitemap.xml`, `robots.txt`
  (страницы приложения закрыты: `Disallow` + заголовок `X-Robots-Tag: noindex`), `manifest.webmanifest`.
- Воронка «визит → регистрация → первый расход» — только счётчики (визиты — в памяти, без IP и cookie;
  регистрации и первые расходы — порт `FunnelSource` → `app/wiring/wire_site.rs`); сводка — в журнал сервера раз в сутки.
- Тарифов и слова «бесплатно» нет, пока не решён вопрос монетизации (проверяется тестом).

Тексты — `src/i18n.rs` (ru/en/th), шаблоны — `templates/site`.
Тесты: `cargo test -p site` — воронка, sitemap/robots, полнота переводов лендинга и правовых страниц, нет «бесплатно».
