# budget — Бюджет (написана вручную)

Отчёт за неделю / месяц / год: факт, план (нерешённые вхождения), прогноз, лимит, «доступно» по дереву категорий.
Своих таблиц нет — все данные через порты: категории, факты (transactions), планы (planning), лимиты, счета, курсы.

Правила (domain.rs, покрыты тестами):
- суммы поддерева сворачиваются к родителю;
- лимит — действующий на конец периода; при другом виде периода пересчитывается по дням;
- «доступно» = min(остаток узла, доступно родителя);
- warn ≥ 80 %, over > 100 %; предупреждение, если лимиты детей больше лимита родителя;
- пересчёт в базовую валюту по курсу на дату (последний известный);
- факты — проводки на категории (возвраты вычитаются, комиссии переводов — расходы); переводы и начальные
  остатки в доходы и расходы не входят, плановые переводы — только в «Предстоящих»;
- остатки счетов — суммы проводок на конец периода; прогноз остатков — плюс нерешённые планы по счёту с начала
  текущего месяца (или периода, если он раньше) по конец периода, перевод между валютами — через базовую;
- курсовая разница — проводки «Обмен валют» за период в базовой валюте (`fx_result`), отдельно от расходов;
- сортировка «Расходов» (`sort_tree`) — только среди братьев, дети остаются под родителем, пустые значения — в конце.

REST: GET `/api/budget?view&date&member`. Страница: `/budget` («Обзор» — стартовая страница вошедшего):
режим сводки «Факт» (по умолчанию: крупно — проведённое, мелко — ожидается и прогноз) или «Прогноз»
(`mode=forecast`: факт + планы, итог и остатки счетов с учётом планов); дерево свёрнуто до 2-го уровня, полоса заполнения (зелёная / янтарная ≥ 80 % / красная > 100 %),
«+» в строке категории открывает быстрый расход с этой категорией. Заголовки «Расходов» сортируют таблицу:
`sort=category|limit|fact|plan|forecast|available|percent&dir=asc|desc` (суммы — сначала по убыванию, третий клик —
порядок справочника); параметры сохраняются при смене периода, режима и участника, JS при сортировке и
обновлении цифр сохраняет свёрнутость дерева.
Для других фич: `month_limits` (остатки лимитов за месяц даты) и `rates_on` (курсы) — предупреждение в форме расхода.
