# Фича `places` — Места (написана вручную по образцу categories)

Магазины, кафе и рынки, где платят. Место подставляет в операцию категорию позиции и счёт, ищется по названию и
вариантам написания (`kernel::search`). ТЗ — docs/group-1.md, раздел 5.8.

- **Тип:** справочник (ключ `code`, архив вместо удаления); `feature.json` нет — `upgrade` фичу не трогает
- **Крейт:** `crates/features/places` (Cargo-флаг приложения `places`, нужны `accounts` и `categories`)
- **Таблица:** `fb_places`
- **Порты:** `Directories` (активные категории и счета) → `crates/app/src/wiring/wire_places.rs`
- **Правила:**
  - код — латиница, цифры и `_`, до 40 знаков, вводится вручную (из названия не создаётся);
  - название не переводится — имя собственное; варианты написания — без повторов и пустых, до 20;
  - категория и счёт по умолчанию — активные записи; ранее выбранная запись, которую потом архивировали, при
    правке остаётся;
  - операции ссылаются на место по коду, поэтому место только архивируется;
  - места — дерево (`parent_code`, по образцу категорий): сеть «7-Eleven» → конкретный магазин, до 3 уровней.
    Родитель — активное место проекта, без циклов. Магазин без своих категории и счёта подставляет значения
    ближайшего родителя (`effective_*` в ответе); полное название — путь от корня без повтора имени родителя и адрес
    («7-Eleven › Terminal 21», «7-Eleven · Asok»); варианты написания родителей находят и магазин;
  - сеть с активными магазинами не архивируется; магазин архивной сети не возвращается из архива.

## Поля

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| code | string | да | Уникальный код в проекте |
| name | string | да | Название, как на вывеске |
| parent_code | string | нет | Сеть или торговый центр, в который входит место |
| aliases | string[] | нет | Варианты написания для поиска |
| default_category_code | string | нет | Категория позиции по умолчанию |
| default_account_code | string | нет | Счёт по умолчанию |
| place_kind | enum (SHOP, CAFE, MARKET, ONLINE, SERVICE, OTHER) | нет | Тип, по умолчанию OTHER |
| location | string | нет | Филиал или адрес |
| archived | bool | — | Архив |

## Эндпоинты

| Метод | Путь | Действие |
|---|---|---|
| POST | /api/places | создать |
| GET | /api/places?page=0&size=100&include_archived=false | список деревом: сеть, затем её магазины |
| GET | /api/places/{code} | получить |
| PUT | /api/places/{code} | изменить (код не меняется, архив — отдельно) |
| DELETE | /api/places/{code} | архивировать |
| POST | /api/places/{code}/restore | вернуть из архива |

Ответ, кроме полей: `depth` (0 — верхний уровень), `title` (полное название), `effective_category_code` и
`effective_account_code` (что место подставит — своё или родителя).

Страницы: `/places`, `/places/new?parent={code}` («+ магазин»), `/places/{code}/edit`.
