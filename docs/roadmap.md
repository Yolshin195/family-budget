# Дорожная карта (аудит 17.10.2026, версия 0.1.0)

Итог аудита кода и план развития: от «цифрам можно верить» до версии 1.0. На момент аудита
`cargo test --workspace` — 219 тестов, все зелёные. Пункты отмечаются `[x]` по мере выхода; вышедшее попадает в
«Что нового» (`site/content/releases/next/`), задуманное, но отложенное, — в `site/content/ideas/`.

## Состояние

Основа сильная:

- деньги — `rust_decimal` и `NUMERIC`, без `f64`; точность суммы сверяется с `minor_units` валюты;
- двойная запись: баланс проводок проверяется в домене (`transactions/src/domain.rs:311`) и отложенным триггером
  в БД, шапка и проводки пишутся в одной SQL-транзакции;
- возвраты, чек с позициями, перевод с обменом и комиссией — одна сбалансированная транзакция;
- безопасность: серверные сессии, CSRF (Origin + HMAC), строгая CSP, PKCE, `project_id` во всех запросах,
  журнал, приглашения по HMAC-ссылке;
- MCP с отдельными правами ассистента и без удаления; три языка, проверенные тестами.

Главные риски: в нескольких местах отчёты **тихо показывают неверные числа**, а SQL и Postgres-адаптеры почти не
покрыты тестами — чем больше функций, тем опаснее изменения.

### Эксплуатация и архитектура

- Нет тестов на Postgres: почти всё — на memory-адаптерах, 117 запросов без `query!`, триггер двойной записи и
  миграции не проверяются; Postgres в CI нет (`rates/src/tests.rs:222` пропускается без `TEST_DATABASE_URL`).
- В CI нет `cargo clippy`, `cargo fmt --check` и проверки, что `app.css` соответствует шаблонам.
- Логи — `eprintln!`; `TraceLayer` подключён без подписчика (`app/src/main.rs:206`); `/health` не проверяет БД
  (`main.rs:179`); нет graceful shutdown (`main.rs:212`) — при обновлении обрываются запросы на запись.
- Одна реплика: «Отменить» (`kernel/src/undo.rs`) и лимит запросов — в памяти процесса, фоновые задачи
  (`main.rs:100,115,131`) — в каждом экземпляре.
- Удаление проекта — 8 `purge` без общей транзакции (`wiring/wire_projects.rs:177-185`); создание проекта тоже
  не атомарно.
- Циклы связок закрыты `OnceLock` (`wiring/mod.rs:59,66,74`): неустановленный порт молча отдаёт значение
  по умолчанию.
- MCP дублирует все фичи (`mcp/src/service.rs` — 1494 строки, `wiring/wire_mcp.rs` — 455): новое поле — правки
  в 4–5 местах. `projects/src/adapters/web.rs` (943 строки) смешивает вход, профиль, участников и приглашения.
- htmx подключён, но не используется (0 атрибутов `hx-*`); `app.js` — 793 строки без тестов.
- Ненайденный ключ i18n молча показывается как сам ключ (`kernel/src/i18n.rs:109-115`).

### Продукт

- Сообщения валидации только на русском (`AppError::Validation(String)` из domain/service) — участник
  с тайским интерфейсом видит их по-русски.
- Курсы — только вручную; нет поиска операций, фильтров по категории/сумме/периоду и пагинации.
- Нет импорта и экспорта, напоминаний, графиков, офлайна на телефоне.
- Нет покупки в другой валюте (карта в THB, оплата в USD), кредиток, долгов, взаиморасчётов, целей,
  переноса остатка лимита, вложений, тегов, месяца с дня зарплаты.
- Коды справочников (`CARD_KBANK`) пользователь придумывает сам; онбординг не предлагает валюты семьи.

## Принципы

- Цифры важнее функций: новое не выходит, пока в отчётах есть известные ошибки.
- Каждая функция проверяется на реальной семье и попадает в «Что нового» на трёх языках.
- Метрики успеха: расход записывается быстрее 5 секунд; доля операций из импорта и Claude; ни одного дня без курса
  для активных валют; семья продолжает вести бюджет через 30 дней.
