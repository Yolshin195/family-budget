# MCP: бюджет через Claude

Сервер MCP (Model Context Protocol) — `https://<домен>/mcp`. Через него Claude (claude.ai, приложение на
телефоне, Claude Desktop, Claude Code) работает с бюджетом **под вашим аккаунтом**: в одном проекте и с теми
правами, которые вы выбрали. Удалять через ассистента ничего нельзя; права меняются только в браузере.

Фича — `crates/features/mcp`, план и решения — [mcp-plan.md](mcp-plan.md).

## Инструменты

| Инструмент | Что делает | Право |
| --- | --- | --- |
| `get_context` | Проект, базовая валюта, валюты, счета с остатками, дерево категорий (ru/en/th), частые категории и места, люди и `my_person_code` (запись пользователя), права | всегда |
| `list_transactions` | Операции за период; фильтры: счёт, вид, категория с подкатегориями, место, для кого (`for`, `all` — для всех), текст | просмотр |
| `get_balances` | Остатки счетов на дату | просмотр |
| `get_budget` | Бюджет недели / месяца / года: лимит, факт, план, прогноз, доступно | просмотр |
| `list_upcoming_payments` | Плановые платежи и их статусы | просмотр |
| `list_plans` | Плановые операции: счёт, категория, сумма, расписание, активна ли | просмотр |
| `list_rates` | Курсы валют за период и последний курс каждой валюты — в обе стороны | просмотр |
| `list_limits` | Правила лимитов и какое действует сегодня | просмотр |
| `list_places` | Места: название, филиал, варианты написания, тип, что подставляют; поиск по тексту | просмотр |
| `list_people` | Люди: код, имя, другие имена, участник ли, `you` — запись пользователя; поиск по тексту | просмотр |
| `add_expense`, `add_income` | Расход / доход: сумма + категория или позиции (чек); `place` подставляет категорию и счёт места; `for` — для кого (у операции и у позиций, `all` — для всех, по умолчанию) | операции |
| `add_transfer` | Перевод и обмен валют между счетами, комиссия | операции |
| `update_transaction` | Исправить операцию, в том числе место (`""` — убрать) и для кого (`for` меняет позиции с прежним общим получателем; у позиций — свой `for`); Claude спрашивает подтверждение | операции |
| `pay_planned` | Оплатить плановый платёж | операции |
| `skip_planned` | Пропустить плановый платёж | плановые операции |
| `add_plan`, `update_plan` | Создать / изменить плановую операцию, `active=false` — приостановить | плановые операции |
| `add_currency`, `update_currency` | Валюта: код, название ru/en/th, символ, знаки после запятой | валюты |
| `add_account`, `update_account` | Счёт: код, название ru/en/th, вид, валюта; начальный остаток — ещё и с правом «операции» | счета |
| `add_category`, `update_category` | Категория: код, название ru/en/th, вид, родитель (перенос), порядок | категории |
| `add_place`, `update_place` | Место: код, название (без перевода), варианты написания, категория и счёт по умолчанию, тип, филиал. Только явно — из чека место не создаётся | места |
| `add_person`, `update_person` | Человек без аккаунта (ребёнок, няня): код (не `ALL`), имя без перевода, другие имена. Только явно; записи участников проекта создаются сами | люди |
| `set_rate` | Курс валюты на дату в любую сторону (`rate` или `inverse_rate`): добавить или заменить курс этой даты | курсы валют |
| `set_limit` | Лимит категории за неделю / месяц / год с даты: добавить или заменить правило этой даты; 0 — тратить нельзя совсем, `remove: true` — снять лимит с даты | лимиты |

Соглашения: суммы — строкой или числом, даты — `YYYY-MM-DD`; названия — текст + `name_lang` (по умолчанию язык
пользователя) + `translations {ru, en, th}`; коды новых записей — `UPPER_SNAKE`; ссылки (валюта, счёт, родитель,
категория, место, человек) — по коду или по названию на любом языке, у места и человека — и по вариантам написания
(без регистра и диакритики, `kernel::search`). Курс `set_rate` передаётся ровно одним из двух аргументов,
как его назвал пользователь: `rate` — сколько единиц **базовой** валюты стоит 1 единица валюты (базовая THB:
1 USD = 36.5 THB → `set_rate(USD, rate=36.5)`), или `inverse_rate` — сколько единиц валюты стоит 1 единица базовой
(1 THB = 2.50 RUB → `set_rate(RUB, inverse_rate=2.5)`, в бюджете 1000 ₽ = 400 ฿). Направление запоминается: в вебе
курс показан так, как его ввели, и следующий курс валюты открывается в той же стороне. Ответ `set_rate` называет
базовую валюту, показывает курс в обе стороны и предупреждает, если курс больше чем в 5 раз отличается от
предыдущего (похоже на перепутанное направление). `list_rates` отдаёт `rate`, `inverse_rate`, `entered` и `inverted`. Лимит — в базовой валюте, по умолчанию с начала
текущего периода (понедельник, 1-е число, 1 января); у категории одно правило на дату начала.

`update_*` и `update_transaction` помечены `destructiveHint` — Claude спрашивает подтверждение; `list_*` и
`get_*` — `readOnlyHint`. Удаления и архива нет: `update_*` не принимают `archived`, а адаптер всегда оставляет
текущий признак архива записи.

## Права

Права выбираются на странице «Ассистенты» (`/assistants`) для Claude через claude.ai или в личном API-токене.

| Право | На странице | Инструменты |
| --- | --- | --- |
| `read` | Просмотр всего (всегда) | `get_*`, `list_*` |
| `transactions:write` | Операции: добавлять и исправлять (по умолчанию ☑) | `add_expense`, `add_income`, `add_transfer`, `update_transaction`, `pay_planned`; начальный остаток счёта |
| `currencies:write` | Справочники → Валюты | `add_currency`, `update_currency` |
| `accounts:write` | Справочники → Счета | `add_account`, `update_account` |
| `categories:write` | Справочники → Категории | `add_category`, `update_category` |
| `places:write` | Справочники → Места | `add_place`, `update_place` |
| `people:write` | Справочники → Люди | `add_person`, `update_person` |
| `rates:write` | Справочники → Курсы валют | `set_rate` |
| `limits:write` | Лимиты | `set_limit` |
| `planning:write` | Плановые операции | `add_plan`, `update_plan`, `skip_planned` |

Новые права по умолчанию выключены. Флажок «Все справочники» отмечает валюты, счета, категории, места, людей и курсы
сразу (и без JS: сервер понимает его как все шесть прав). Выбирать существующие места и людей в операциях можно с правом
«операции». Права не выше роли: у VIEWER — только просмотр. Личный токен
`write` даёт всё, `accounts:write` — только счета (и их просмотр).

`tools/list` показывает только разрешённые инструменты, и каждый вызов ещё раз проверяет права и роль в
проекте. Каждое изменение через ассистента пишется в журнал безопасности («Профиль → Безопасность», событие
`mcp_write`: инструмент, клиент, код или id записи). После изменения прав начните в Claude новый чат (или
переподключите коннектор) — Claude запрашивает список инструментов в начале разговора.

## Вход

| Клиент | Как входит | Проект и права |
| --- | --- | --- |
| Claude Code, MCP Inspector | Личный API-токен `fbt_…` в заголовке `Authorization` | у токена |
| claude.ai, приложение Claude на телефоне и компьютере | OAuth через провайдера входа (сейчас Rauthy): access-токен, выпущенный для ресурса `https://<домен>/mcp` | страница «Ассистенты» (`/assistants`) |

Токен провайдера сам по себе прав не даёт: пока на странице «Ассистенты» не открыт доступ, Claude видит
только подсказку открыть её. Отключение там действует сразу.

### Claude Code

1. «Профиль → Безопасность → API-токены»: проект и права (например, «операции»), срок.
2. `claude mcp add --transport http family-budget https://<домен>/mcp --header "Authorization: Bearer fbt_…"`

### claude.ai (и приложение на телефоне)

**Один раз — клиент в Rauthy** (админка Rauthy → Clients → New client; на стенде `make` клиент `claude`
создаётся из `deploy/rauthy/bootstrap/clients.json`, но два поля ниже всё равно задать вручную):

| Поле | Значение |
| --- | --- |
| Client ID | `claude` (как `MCP_OAUTH_CLIENT_ID`) |
| Confidential | нет (публичный клиент, PKCE S256) |
| Redirect URIs | `https://claude.ai/api/mcp/auth_callback` |
| Flows | `authorization_code`, `refresh_token` |
| Scopes | `openid` (+ `profile`, `email`) |
| **Allowed resources** | `https://<домен>/mcp` |
| **Default audience** | `https://<домен>/mcp` — нужен для входа через GitHub/Facebook: для них Rauthy 0.37 не обрабатывает `resource` |
| Access token lifetime | 3600 |

**На сайте:** «Профиль → Безопасность → Ассистенты (MCP)» → выбрать проект и права → «Сохранить доступ».

**В claude.ai:** «Настроить» (Customize) → «Коннекторы» → «+» → «Добавить свой коннектор»:

- адрес: `https://<домен>/mcp` (ровно так, без слеша в конце);
- «Дополнительные настройки» → свой OAuth-клиент, Client ID `claude`, секрет пустой
  (CIMD и автоматическая регистрация у Rauthy с Claude не работают — см. mcp-plan.md);
- «Подключить» → вход в Rauthy → коннектор доступен и в приложении на телефоне.

Требования к серверу: HTTPS, доступ из интернета по IPv4 (Claude ходит из облака Anthropic).

## Проверка

```bash
# Без токена — 401 и адрес метаданных
curl -si -X POST https://<домен>/mcp | grep -i www-authenticate
# Метаданные ресурса (RFC 9728): издатель токенов — Rauthy
curl -s https://<домен>/.well-known/oauth-protected-resource/mcp
# С личным токеном — список инструментов
curl -s -X POST https://<домен>/mcp -H "Authorization: Bearer fbt_…" -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' -H 'MCP-Protocol-Version: 2025-06-18' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
```

Или MCP Inspector: `npx @modelcontextprotocol/inspector` → Streamable HTTP, `http://localhost:8080/mcp`,
заголовок `Authorization: Bearer fbt_…` (в dev разрешены `localhost` и `127.0.0.1`).

## Переезд на другой провайдер входа

MCP-часть от провайдера не зависит: она получает «пользователь + OAuth-клиент» через порт `Accounts`.
Если новый провайдер выдаёт JWT access-токены с `aud` = `https://<домен>/mcp` (RFC 8707 / 9068), достаточно
сменить `OIDC_ISSUER` и завести у него клиент `claude` — проверка (`verify_access_jwt` в
`crates/features/projects/src/adapters/oidc.rs`) та же. Иначе (непрозрачные токены) — заменить только этот
метод адаптера на интроспекцию (RFC 7662). Когда провайдер сам покажет экран согласия с выбором проекта,
страница «Ассистенты» станет делегированным согласием, а таблица `fb_mcp_grants` останется источником прав.
