# 02. Story Map

Путь участника семьи, который ведёт бюджет через ассистента. Хребет — слева направо, под шагом — варианты,
сверху самые важные. Срез: **MVP** — сделано и нужно каждый день, **Следующий релиз** — доработки и найденные
ошибки, **Потом** — новое.

## Хребет

```
Подключить     →  Записать     →  Сверить и    →  Платить     →  Настроить     →  Спросить     →  Проверить, что
ассистента        трату           исправить       по плану       бюджет           о деньгах       делал ассистент
```

## Детали и срезы

| Шаг хребта | MVP (есть) | Следующий релиз | Потом |
| --- | --- | --- | --- |
| **1. Подключить ассистента** | Права и проект на странице «Ассистенты»; OAuth для claude.ai и ChatGPT; API-токен для Claude Code; без доступа — подсказка со ссылкой | Доступ гаснет при исключении из проекта (H6) | Подключение «только адрес» (CIMD), другие ассистенты — идея `more-assistants` |
| **2. Записать трату** | «Кофе 120» голосом; чек по фото с позициями, количеством и скидкой; доход; место подставляет категорию и счёт; «для кого»; переводы на три языка; предупреждение «нет курса», «счёт не в базовой валюте»; остаток лимита | «Сегодня» по поясу пользователя (H4) | Черновик из SMS/уведомления `add_draft` (roadmap) |
| **2a. Перевод и обмен** | Перевод, обмен с полученной суммой, комиссия | — | — |
| **3. Сверить и исправить** | Дополнить операцию из SMS вместо дубля; исправить операцию после подтверждения | Защита от дубля на сервере, не только в инструкции (H2) | Удаление с отменой по отдельному праву (G1) |
| **4. Платить по плану** | Список платежей со статусами; оплатить, пропустить; создать, изменить, приостановить план | Оплата планового обмена валют (H3) | Вернуть пропущенный платёж (`unskip_planned` из плана) |
