| ID | Требование | Реализация | Источник | Оценка |
| --- | --- | --- | --- | --- |
| X-01 | Свой OAuth-сервер в приложении, CIMD, экран согласия (`plan` разделы 1–2, 5) | OAuth выдаёт Rauthy, права заранее на странице «Ассистенты», Client ID вручную | `plan` «Статус» | принято владельцем («план Б») |

| X-09 | Данные не теряются молча | обрезка на 1000 / 200 строк без признака | `svc:178-182`; `debt` №25 | **ошибка** (F-14.R4) |
