# 01. Impact Map

## Why — зачем существует агент

**Цель:** семья ведёт общий бюджет, не открывая приложение: расход записывается голосом или по фото чека за секунды,
а на вопрос «сколько потратили / сколько осталось» ассистент отвечает сам. Ассистент работает под аккаунтом
пользователя, только в выбранном проекте и с выбранными правами (`docs/mcp-plan.md`, «Цель»; README, «MCP для Claude»).

**Метрики** (`docs/roadmap.md`, «Принципы»):

| Метрика | Целевое значение | Источник |
| --- | --- | --- |
| Время записи расхода | < 5 секунд | roadmap, «Метрики успеха» |
| Доля операций из импорта и Claude | **не задано** — вопрос Q-01 | roadmap, «Метрики успеха» |
| Семья ведёт бюджет через 30 дней | да / нет | roadmap, «Метрики успеха» |

Проверка готовности этапа 4 плана: «с телефона голосом „запиши кофе 120 бат“ → операция появилась на „Обзоре“ у
второго участника» (`docs/mcp-plan.md`, раздел 7).

## Who — акторы

| Актор | Роль | Источник |
| --- | --- | --- |
| Участник семьи (OWNER, EDITOR) | Говорит с ассистентом: записывает траты, спрашивает про бюджет; открывает и отзывает доступ | `mcp.md` «Права» |
| Участник с ролью VIEWER | Может только смотреть — и ассистент у него только смотрит | `mcp.md` «Права»; тест `viewer_role_limits_grant_and_calls` |
| Другие участники проекта | Видят записи ассистента в приложении (в том числе на тайском) | `plan` раздел 4 «Описание на трёх языках» |
| Ассистент (Claude, ChatGPT, Claude Code) | Клиент MCP: понимает речь и фото, зовёт инструменты | `mcp.md` «Вход» |
| Провайдер входа (Rauthy) | Вход, OAuth-клиенты, выдача токенов | `mcp.md` «claude.ai» |
| Банк (SMS) | Сам создаёт операции с фактами (сумма, счёт, дата) без категории | `docs/external-refs.md`; `srv:37` |
| Журнал безопасности | Хранит каждое изменение через ассистента 1 год | `mcp.md` «Права» |

## How — как меняется поведение

| Актор | Было | Стало |
| --- | --- | --- |
| Участник семьи | Открывает приложение, заполняет форму; чек переносит вручную по строкам | Говорит «кофе 120» или фотографирует чек — запись появляется сама, с остатком лимита |
| Участник семьи | Чтобы узнать остаток, открывает «Бюджет» и считает | Спрашивает ассистента и получает ответ с цифрами |
| Участник семьи | Боится дать ИИ доступ к деньгам | Сам выбирает проект и права; удалить ничего нельзя; всё видно в журнале |
| Участник с тайским интерфейсом | Видит чужие записи на чужом языке | Видит описание на своём языке — ассистент сразу пишет переводы |
| Банк + участник | SMS создаёт «пустую» операцию, к ней же человек добавляет вторую вручную — дубль | Ассистент дополняет операцию из SMS, а не создаёт вторую |
| Ассистент | — | Видит только разрешённые инструменты; данные из базы не принимает за команды |

## Пометки

**Кандидаты на удаление** (возможность без связи с целью): не найдено. Все 28 инструментов служат одной из
возможностей. Пересечение — `get_balances` и остатки в `get_context`: первый нужен для остатков *на дату*,
поэтому оставлен (см. 06, D-04).

**Пробелы** (цель или изменение поведения без возможности):

| ID | Пробел | Источник |
| --- | --- | --- |
| G1 | Удаление с отменой по отдельному праву — обещано планом, не сделано | `plan` разделы 3–4, «Статус»; `debt` №54 |
| G2 | Импорт выписки банка пакетом с поиском дублей | `plan` раздел 7, этап 5; roadmap |
| G3 | Промпт «итоги месяца» | `plan` раздел 7, этап 5; roadmap |
| G4 | Метрика «доля операций от Claude» не считается — нет источника цифры | roadmap «Метрики успеха» |
| G5 | Проверка поведения модели (evals) — нет | этап 0, H10 |

**Контрольная точка 2:** цель, акторы и метрика — на подтверждение владельцу (вопросы Q-01, Q-02 в 06).
