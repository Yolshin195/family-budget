# 04. Example Mapping — карта правил, примеров и вопросов

Шаг 1 этапа 4 (Example Mapping по Мэтту Уинну): до Gherkin — правила, короткие названия примеров и вопросы.
Шаг 2 — файлы `F-nn-*.feature` рядом. 🤖 (`@model`) — поведение модели, сервером не проверить; «заблокирована»
(`@blocked`) — ждёт ответа на вопрос. Вопросы — в [06-questions-gaps.md](../06-questions-gaps.md), покрытие тестами —
в [05-registry.md](../05-registry.md).

Сигналы: правил больше 6 — фичу пора делить; примеров у правила больше 4 — правило сложное; блокирующий вопрос —
фича не готова к детализации. Сейчас больше 6 правил только у F-01 (8) и F-11 (7): обе — наборы проверок одного
вида (права, справочники), делить не стали.
