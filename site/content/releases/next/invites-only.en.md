You can now add someone to a budget only with an invite link — "Add by email" is gone: only a person who opened the link themselves joins. A "View the demo" guest sign-in lasts one day, a sign-in error is shown without technical details, and an API token issued without a second factor stops working once the owner turns on "Require 2FA from members".
