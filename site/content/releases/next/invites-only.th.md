ตอนนี้เพิ่มคนเข้างบประมาณได้ด้วยลิงก์คำเชิญเท่านั้น — นำ "เพิ่มด้วยอีเมล" ออกแล้ว: เข้าร่วมได้เฉพาะคนที่เปิดลิงก์เอง การเข้าแบบผู้เยี่ยมชมผ่าน "ดูเดโม" ใช้ได้หนึ่งวัน ข้อผิดพลาดในการเข้าสู่ระบบแสดงโดยไม่มีรายละเอียดทางเทคนิค และโทเคน API ที่ออกโดยไม่มีปัจจัยที่สองจะใช้ไม่ได้เมื่อเจ้าของเปิด "บังคับให้สมาชิกใช้ 2FA"
