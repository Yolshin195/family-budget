- การเปลี่ยนวันเริ่มหรือการทำซ้ำของแผนที่เคยชำระแล้วจะไม่ทำให้การชำระที่ผ่านมาหายไป และไม่สร้างรายการ "เลยกำหนด" ย้อนหลัง: แผนเดิมจะปิดลง และกฎใหม่มีผลตั้งแต่วันนี้
- บันทึกการชำระได้เฉพาะรายการจริงของแผน: ที่ไม่ได้ข้าม ตรงกับวันที่ตามกฎ และเป็นประเภทเดียวกัน — ก่อนหน้านี้ API รับวันที่ "ผิด" ได้ และยอดคาดการณ์นับการชำระซ้ำสองครั้ง
- เปลี่ยนประเภทของหมวดหมู่ไม่ได้ถ้ามีรายการ แผน หรือวงเงินแล้ว รายจ่ายจึงไม่กลายเป็นรายรับ
- สกุลเงินมีทศนิยมได้ 0 ถึง 4 ตำแหน่ง และลดลงไม่ได้ถ้ามียอดแล้ว สกุลหลักและสกุลที่ยังมีบัญชีใช้งานอยู่จะเก็บถาวรไม่ได้
- กด "บันทึก" สองครั้งในแบบฟอร์มบัญชีจะไม่บันทึก "ยอดคงเหลือ" ของบัญชีซ้ำอีก
