ตอนนี้ติดต่อเราได้ทาง GitHub Issues ซึ่งไม่สะดวกสำหรับทุกคน เราอยากเพิ่ม:

- **แบบฟอร์มรีวิว** ที่หน้า[รีวิว](@/feedback.th.md): เขียนได้โดยไม่ต้องมีบัญชี GitHub และรีวิวที่คุณอนุญาตให้เผยแพร่จะแสดงที่นั่นในสามภาษา
- **ความคิดเห็นใต้บทความ** ในบล็อก — เพื่อพูดคุยเรื่องรีลีส คู่มือ และไอเดียได้ตรงจุด

ระบบความคิดเห็นจะทำงานบนเซิร์ฟเวอร์ของเรา ไม่มีโฆษณาและตัวติดตามจากภายนอก และเราเตรียมพื้นที่สำหรับมันไว้บนเว็บไซต์แล้ว
