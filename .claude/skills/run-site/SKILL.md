# Сайт: запустить и посмотреть

Проверено в облачной среде Claude Code (Linux, Node 22, Chromium в `/opt/pw-browsers`). Docker и Zola в среде нет —
Zola скачивается скриптом той же версии, что в CI. Пути — от корня репозитория.

## 1. Зависимости — один раз за сессию

```bash
npm ci --no-audit --no-fund                 # puppeteer-core, Tailwind, шрифты, иконки
ZOLA=$(.claude/skills/run-site/zola.sh)     # версия и sha256 — из .github/workflows/site.yml, кэш в ~/.cache
```

## 2. Собрать и запустить

```bash
npm run site:assets                                             # CSS, иконки, шрифты → site/static/assets
(cd site && "$ZOLA" build --force --base-url http://localhost:8765)
```

Сервер — отдельной командой в фоне (`run_in_background`), он переживает пересборки:

```bash
python3 -m http.server 8765 --directory site/public
```

- `--base-url` обязателен: иначе все ссылки и CSS ведут на `family-budget-555.ru` из `config.toml`.
- После правок — снова `npm run site:assets` (если менялись стили или шаблоны) и `zola build`; сервер не трогать.
- Не останавливайте сервер `pkill -f "http.server 8765"` внутри той же команды: шаблон совпадает с самой оболочкой,
  и она падает с кодом 144. Останавливайте фоновую задачу по её id.
- Быстрая проверка: `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8765/articles/roadmap/` → `200`.

## 3. Пройти в браузере

```bash
node .claude/skills/run-site/drive.mjs --page /articles/roadmap/ [--page /guides/limits/]
```

Для каждой страницы и языка (`/en`, `/th` — префиксом) скрипт снимает первый экран и всю страницу на компьютере
(1280 px, светлая тема) и первый экран на телефоне (390 px, тёмная), печатает ошибки консоли, неудачные запросы,
ответы 4xx/5xx и горизонтальную прокрутку; код выхода 1, если что-то нашлось. Снимки — в `site/.build/shots`
(в git не попадают).

**Посмотрите снимки** (Read): пустой кадр, текст без шрифта, налезающие блоки — тоже провал. Полностраничный снимок
длинной статьи сжимается до нечитаемого — вырежьте нужный кусок (`sharp` есть в node_modules) или снимите элемент.

Если нужен путь пользователя (лендинг → блог → вкладка → статья → переключатель языка), напишите короткий сценарий
по образцу `drive.mjs`: `page.click()` вместе с `page.waitForNavigation()`, перед снимком прокрутка
`el.scrollIntoView()` и `window.scrollBy(0, -90)` — шапка сайта липкая и закрывает верх элемента.

## 4. Ссылка для пользователя

Пользователь смотрит из приложения Claude: `localhost` контейнера ему недоступен, GitHub Pages из контейнера
не открывается, а ветка на Pages не публикуется. Опубликуйте превью страницы как приватный Artifact:

```bash
python3 .claude/skills/run-site/preview.py /articles/roadmap/
```

Скрипт собирает сайт во временную папку, кладёт в `site/.build/preview` три языка страницы и нужные ассеты
с относительными ссылками и страницу-оглавление `preview.html`, печатает JSON. Опубликуйте инструментом Artifact:
`file_path` и `root` — из JSON, `files` — список из JSON, `icon` — одно слово (например, `map`), `description` —
одно предложение. Повторная публикация того же `file_path` обновляет ту же ссылку. Ссылки на другие разделы
сайта в превью ведут на GitHub Pages; скажите об этом пользователю.

## Перед PR

`python3 scripts/check_site.py` (три языка, структура, ссылки) и `(cd site && "$ZOLA" check --skip-external-links)`.
Правила текстов и вёрстки — `site/README.md`, общие правила — `CLAUDE.md`.

## Подводные камни

- Tailwind сайта — дизайн-система приложения (`tailwind.config.cjs`): радиусы только `sm`, `md`, `lg`, `xl`, `full`
  (нет `2xl`), цвета — токены (`bg-accent`, `text-muted`…). Неизвестный класс в `@apply` роняет `npm run site:assets`.
- Классы ищутся в `site/templates` и `site/content`; собранные из данных (`kind-*`, `status-*`) — через `safelist`
  в `site/tailwind.config.cjs`.
- В `styles/app.css` уже есть компоненты лендинга (`.chat`, `.msg`, `.step`…) — проверьте имя, прежде чем заводить
  своё, и переиспользуйте.
- Лента блога сортирует по `date`; у гайдов дата со временем (`2026-10-17T18:00:00`) — чтобы новый материал шёл
  первым, ставьте время позже.
