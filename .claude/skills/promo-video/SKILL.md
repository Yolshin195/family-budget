# Рекламные ролики (TikTok / Reels / Shorts)

Ролик — HTML-страница с анимациями, которую Chromium снимает покадрово, а ffmpeg склеивает в MP4. Всё лежит в
`marketing/promo-video/`:

- `scenarios/<slug>.js` — **сценарий ролика**: сцены, тексты на трёх языках, кадры и движение камеры. Новый ролик —
  новый файл; образец — `scenarios/pains.js` («боль → решение», ~30 с).
- `engine.js` — движок: типы сцен, анимации, плавная смена сцен. Меняется, только если нужен новый тип сцены.
- `index.html` — стили и холст 1080×1920.
- `render.mjs` — рендер в MP4, отдельный кадр или лист проверки; `grid.mjs` — сетка координат на скриншоте.
- `out/` — готовые `<slug>.<язык>.mp4` и обложки `<slug>.cover.<язык>.jpg` (коммитятся).

## Порядок работы

### 1. Окружение
Сначала, как требует CLAUDE.md, одной строкой скажите, где вы запущены. Потом проверьте инструменты:

- **Облако:** `npm ci`; браузер — `export CHROMIUM=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`
  (если версия другая — `ls /opt/pw-browsers`); ffmpeg уже есть.
- **Mac:** `npm ci`, `brew install ffmpeg`;
  `export CHROMIUM="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`.

### 2. Замысел
Уточните у пользователя, только если из просьбы непонятно: **о чём ролик** (боли, одна возможность, релиз),
**для кого** и **длительность** (15–30 с; по умолчанию ~25–30). Языки не спрашивайте — всегда все три.

Хорошая структура: крючок 2–2,5 с → 3–6 сцен по 3,5–4 с → финал с призывом 3–3,5 с. Одна сцена — одна мысль.

### 3. Кадры
Скриншоты берутся из гайдов сайта — их уже три языка и одинаковая раскладка:

```bash
find site/content/guides -name '*.ru.webp' | sort
```

Нужного экрана нет — сначала снимите его для гайда (`scripts/guide-screenshots.mjs`, нужен `make dev` с демо-данными):
ролик не должен показывать то, чего нет в документации. Данные на скриншотах — только демо-семья; настоящий бюджет
пользователя через MCP в ролики не попадает.

### 4. Сценарий
Скопируйте `scenarios/pains.js` в `scenarios/<slug>.js` и перепишите. Типы сцен:

| type | Поля | Что на экране |
|------|------|---------------|
| `hook` | `text: {ru: [строка1, строка2?, вопрос?]}`, `flying` (эмодзи или `false`) | крупный текст по центру, летящие эмодзи |
| `shot` | `img`, `aspect`, `from`, `to?`, `rings?`, `typing?`, `coins?`, `emoji?`, `text: {ru: [боль, заголовок, подзаголовок]}` | плашка «боль» зачёркивается → заголовок с галочкой → карточка со скриншотом, камера едет `from → to` |
| `chat` | `text: {ru: {pain, title, messages}}`; сообщение — `{me}`, `{bot}` (можно `<b>`), `{tool}`, `{receipt, total}`, у каждого `at` | переписка с Claude |
| `cta` | `text: {ru: {name, tag, btn, langs?}}`, `url?` | логотип, слоган, кнопка, адрес |

У каждой сцены `dur` в секундах. В `shot` боль можно оставить пустой (`''`) — тогда сразу заголовок (для роликов
«смотрите, что умеет»).

**Координаты** в `shot` — в пикселях скриншота 1280×800: `img` — путь без `.<язык>.webp`, `from`/`to` —
`{x, y, w}` (высота = `w / aspect`); `aspect` — форма карточки (1,1–1,6; 1,3 — хорошо для таблиц);
`rings` — `{x, y, w, h, at, ok?}` рамки-подсветки (`ok` — синяя, иначе красная), `typing` — `{x, y, w, h, text, at}`
набор текста поверх поля, `coins` — значки внизу (`['฿', '₽', '$']`). `at` — секунды от начала сцены; камера
едет с ~1,2 до конца сцены, рамку ставьте на ~2,3–2,6, когда она уже в кадре. Координаты подбирайте по сетке:

```bash
node marketing/promo-video/grid.mjs site/content/guides/overview/overview.ru.webp   # → out/grid.png, посмотреть Read
```

### 5. Тексты
- **Три языка сразу**, у каждой сцены `ru`, `en`, `th`; нет перевода — рендер падает с ошибкой.
- **Названия разделов и кнопок — точно как в интерфейсе** этого языка: ищите в `crates/**/i18n.rs`
  (`grep -rn '"Календарь"' crates --include=i18n.rs`).
- **Только правда:** обещания — из лендинга (`site/content/_index*.md`) и гайдов. Нет там «бесплатно» — не пишите.
- **Коротко:** боль ≤ 40 знаков, заголовок ≤ 30, подзаголовок ≤ 60. Тайский — ещё короче: в нём нет пробелов,
  длинная строка вылезает за край.
- Тексты финала и переписки с Claude можно брать с лендинга (`[extra.chat]`, `[extra.cta]`).

### 6. Проверка глазами — обязательно
Лист «конец каждой сцены» на каждом языке, и посмотреть его (Read):

```bash
node marketing/promo-video/render.mjs <slug> ru sheet   # → out/<slug>.sheet.ru.png; так же en и th
```

Проверьте: текст не вылезает за край и не обрезан (особенно тайский), рамки попадают в нужное место и видны
целиком, в карточке нет пустого белого поля за краем скриншота. Важное — в безопасной зоне: верх ≥ 150 px,
низ ≤ 1500 px, справа ~120 px перекрывают кнопки TikTok. Сомнительный момент — отдельный кадр:
`render.mjs <slug> ru 7.2` → `out/<slug>.frame.ru.png`.

### 7. Рендер и сдача
```bash
node marketing/promo-video/render.mjs <slug>    # все языки, ~1,5 мин на язык
ffprobe -v error -show_entries format=duration:stream=width,height -of compact marketing/promo-video/out/<slug>.ru.mp4
```

Отправьте пользователю три MP4 (SendUserFile), закоммитьте сценарий и `out/` (кадры проверки и сетка в
`.gitignore`), добавьте строку в таблицу роликов в `marketing/promo-video/README.md`. Пользователь продукта ролик в
приложении не видит — в PR `Changelog: none`, запись в «Что нового» не нужна.

В ответе: сценарий по сценам (боль → решение), длительность, что учесть при публикации — звука нет, музыку
добавляют в самой соцсети (трендовый звук даёт охват).

## Новый тип сцены
Если ни один тип не подходит (например, сравнение «было/стало» или график), добавьте функцию в `SCENES` в
`engine.js` по образцу `shot`: анимации — через `anim`/`pop`/`rise` с абсолютным временем `start + …`, тексты — через
`tr(sc.text, …)`. Стили — в `index.html`. После правки движка пересоберите лист проверки `pains`, чтобы убедиться,
что старый ролик не сломался.
